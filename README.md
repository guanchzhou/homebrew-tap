# homebrew-tap

Homebrew tap for tools by [guanchzhou](https://github.com/guanchzhou).

| Name | Type | Description |
| --- | --- | --- |
| [c3s](https://github.com/guanchzhou/c3s) | Formula | Kubernetes TUI client |
| [zig-telegram](https://github.com/guanchzhou/zig-telegram) | Formula | Telegram Bot API & MTProto SDK and CLI in pure Zig |
| [threemf](https://github.com/guanchzhou/threemf) | Cask (macOS) | Quick Look plugin for `.3mf`, `.stl`, and `.gcode` files |

## Install

```sh
brew tap guanchzhou/tap
brew trust guanchzhou/tap

brew install c3s
brew install zig-telegram
brew install --cask threemf
```

`brew trust` marks this non-official tap as trusted so Homebrew may load its
formulae and casks.

If `threemf.app` is already in `/Applications` from a manual install
(release zip or local build), let Homebrew take it over:

```sh
brew install --cask --adopt threemf
```

## Updates

Formula and cask files are regenerated by each project's release workflow
when a new version is tagged. Edits made directly in this repository are
overwritten on the next release, so change the template in the project's
`.github/workflows/release.yml` as well.
